# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。**工区没经值班长点头不能报测缝**：测量员先在「放行专页」为自己负责的工区提交开放申请，值班长点头后该工区写口才开；没点头时送单被后端 403 退回。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 放行规则

- 测量员只能为**自己负责**的工区提交开放申请；申请落库同时写一条放行流水。
- 值班长**点头/驳回**与放行流水在**同一事务**落库，只写一半整体回滚。
- **自己不能给自己负责的工区点头**（带班测量员即使带着值班长权限也一样）。
- 巡检员若带值班长权限可以点头，但仍不是测量员、**不能报送**。
- 写口门禁在后端 `POST /api/logs` 强校验，前端禁用只是辅助。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 放行专页

页眉点「放行专页」进入：左边**等候工区**（未申请/已驳回可提交申请，等候中可点头或驳回），右边**已放开清单**，底下**滚动流水**（申请/点头/驳回全留痕，悬停暂停）。
