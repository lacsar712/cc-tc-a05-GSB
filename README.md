# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。**工区未经值班长点头放行不能报测**：测量员先在「放行专页」提交开放申请，值班长点头后该工区写口才打开。点头动作与放行流水在同一事务落库，只写一半不算数。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 放行规则

- 工区三态：未申请（closed）→ 候点头（pending）→ 已放开（open）。
- 未点头（含候点头中）报测，写口一律 403 退回。
- 点头与流水同一事务提交：任一写库失败整体回滚，不留半成品。
- 自己不能给自己负责的工区点头（即使是值班长本人负责的工区）。
- 巡检员带值班长权限时可以点头，但没有报送权限，仍不能报测。
- 放行专页：页眉进入，左列等候工区、右列已放开清单，底部滚动放行流水（自动刷新到底）。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16
